# rh_pricing
Support scripts for ride-hailing pricing models


This repository contains support scripts for data analysis associated with the manuscript "How much should this ride cost? A proposed revenue-neutral pricing scheme to incentivize ride-hailing trips to complement rather than compete with transit" by Zhihua Jin, et al.  Please contact Ms. Jin for additional scripts and details.  

The main content of this repository includes:

/calibration - scripts to create calibration targets and to calibrate a simple mode choice model.
