Scripts and associated files to build skims.

## Environment

The transit skims are built with [r5py](https://r5py.readthedocs.io/), which runs the R5
routing engine and therefore requires **Java 21** (the system default Java 8 will not work).
The cleanest setup is a dedicated conda environment from conda-forge, which provides r5py,
its bundled OpenJDK 21, a working geopandas, and `osmium-tool` (used to clip the OSM street
network in `Download OSM.ipynb`):

```
conda create -n rh_pricing -c conda-forge python=3.11 r5py geopandas pyarrow jupyter osmium-tool
conda activate rh_pricing
```

Then run the notebooks in order:

1. `Download OSM.ipynb` - downloads the Illinois OSM extract and clips it to Cook County,
   writing `data/cook_county.osm.pbf` (the street network r5py needs for walk legs).
2. `Make Skims.ipynb` - builds the transit travel-time skims from the GTFS feeds, OSM
   network, and tract centroids.

## Data

/data - This folder is ignored by git, so you will need to put the files needed to run the scripts here manually.  This includes the following files:

- GTFS files downloaded from https://mobilitydatabase.org for CTA, Metra and Pace, corresponding to the dates
  closest to April 2024.  

- tract_2020_district.csv - equivalency between 2020 Census tracts and RH_Zone.  Must include GEOID as the Census tract ID and RH_Zone as the 2020 TNP Pricing Zone -- Downtown, Tourist, Airport, Other or External.  External is outside the City of Chicago. Must also include lat-lon of Census tract centroid.  

- times-0.0.1-car-2020-tract-17-0.parquet - Car travel times between Census tracts in Illinois.  Downloaded from https://opentimes.org/ 

- cook_county.osm.pbf - OSM street network for Cook County, used by r5py for the walk
  access/egress/transfer legs of transit trips.  Not added manually -- it is generated by
  `Download OSM.ipynb`.

/out - Scripts will write all outputs here.  Ignored by git.
